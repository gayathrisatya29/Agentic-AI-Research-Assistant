# Research Assistant Bot

A beginner-friendly Agentic AI research assistant built while learning
Python, LangChain, tool calling, LangGraph, and LangFuse.

## Current Progress

### Module 1 - Foundations

- Python dataclasses
- Type hints
- Async programming
- Environment variables
- Git and GitHub
- Prompt engineering
- Message roles
- Pydantic structured outputs
- Token counting

## Project Structure

- `models.py` - ResearchQuery dataclass
- `main.py` - Python and async basics
- `prompt_eval.py` - Prompt evaluation
- `messages.py` - Message roles and conversation history
- `research_plan.py` - Pydantic structured output
- `token_count.py` - Token counting
